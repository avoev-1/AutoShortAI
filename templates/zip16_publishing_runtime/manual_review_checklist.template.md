# Manual Publishing Review Checklist

- [ ] Rendered media exists.
- [ ] Media matches target platform capability profile.
- [ ] Title is valid.
- [ ] Description/caption is valid.
- [ ] Hashtags are appropriate.
- [ ] Target account/channel is correct.
- [ ] Visibility is correct.
- [ ] Scheduled time is correct if used.
- [ ] Content maturity rating is correct.
- [ ] No credentials or tokens appear in metadata.

## Restricted Adult / X Creator Checks

- [ ] Restricted mode is intentionally enabled.
- [ ] All participants are confirmed 18+.
- [ ] Consent metadata reference exists.
- [ ] Age gate is required.
- [ ] Restricted account is isolated.
- [ ] Manual review is approved.
- [ ] No illegal or non-consensual content.
- [ ] No content involving minors.
