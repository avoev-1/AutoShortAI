# ZIP17 Project Layout Example

```text
workspace/
  projects/
    ai_news_short_001/
      project.manifest.json
      scripts/
        script_v1.md
      audio/
        voiceover_v1.wav
      images/
        background_001.png
      video/
        draft_preview.mp4
      subtitles/
        captions.srt
      thumbnails/
        thumbnail_v1.png
      metadata/
        publishing_metadata.json
      exports/
        final_youtube_shorts.mp4
        final_tiktok.mp4
      versions/
        version_manifest.json
```

Restricted creator projects must use the restricted workspace root and must not be mixed with general projects.
