# Human Control Policy

The AI can self-validate routine work.

Human approval is mandatory for:
- public YouTube upload/publish
- real OAuth credentials
- paid API usage
- deleting non-temp production data
- changing monetization strategy
- legal/platform policy decisions

Future UI must provide:
- pause all automation
- approve/reject video
- set spend limits
- set daily upload caps
- emergency stop
- storage cleanup approvals
