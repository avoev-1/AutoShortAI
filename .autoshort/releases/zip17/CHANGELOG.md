# ZIP17 Changelog

## Added

- Local Workspace architecture.
- Media Library contracts.
- Workspace project manifests.
- Lightweight versioning models.
- Import/export contracts.
- Search and tagging contracts.
- Restricted / Adult Creator workspace isolation readiness.

- Templates and examples.

- No cloud sync.
- No SaaS feature.
- No heavy UI.
- No video editor implementation.
- No real publishing implementation.
- No secrets vault implementation.
