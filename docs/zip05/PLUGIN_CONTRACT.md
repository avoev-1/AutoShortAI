# Publisher Plugin Contract

Every platform plugin must provide:

```python
class PublisherPlugin:
    plugin_id: str
    platform_name: str
    capabilities: dict

    def validate_account(self, account_ref): ...
    def validate_asset(self, asset_ref, metadata): ...
    def adapt_metadata(self, campaign, target): ...
    def publish(self, job): ...
    def get_status(self, publication_ref): ...
    def collect_analytics(self, publication_ref): ...
    def refresh_auth(self, account_ref): ...
```

Plugin manifests must declare limits and supported features so the Core can plan safely without knowing platform internals.
