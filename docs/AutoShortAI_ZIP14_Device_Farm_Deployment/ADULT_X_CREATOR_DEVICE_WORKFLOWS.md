# Adult / X Creator Device Workflows

AutoShortAI will support a dedicated opt-in Adult / X Creator Mode later.

For ZIP14 this means device workflows can carry restricted creator metadata:

- maturity rating
- restricted platform category
- consent metadata requirement
- all participants 18+ requirement
- age gate requirement
- manual review requirement
- isolated device assignment
- isolated account binding
- restricted logs

This is not unrestricted adult automation. It is a safe architecture category for legitimate adult creators.
