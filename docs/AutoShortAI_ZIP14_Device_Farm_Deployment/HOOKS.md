# Device Farm Hooks

ZIP14 introduces these hooks:

- before_device_registered
- after_device_registered
- before_device_task_assigned
- after_device_task_assigned
- before_device_command_sent
- after_device_response_received
- after_device_failed
- before_device_removed
- after_device_health_check
- before_restricted_device_dispatch
- after_restricted_device_dispatch
