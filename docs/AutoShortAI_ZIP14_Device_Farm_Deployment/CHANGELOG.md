# CHANGELOG — ZIP14 Device Farm Deployment

## Added

- Device Farm architecture release.
- Device node, status, type, health, capability, task, assignment, and heartbeat contracts.
- Device registry and router contracts.
- Worker deployment contracts.
- Phone farm readiness contracts.
- Platform-agnostic device requirement contracts.
- Restricted / Adult X Creator Mode device workflow readiness.
- Secure communication contracts.
- Device farm hooks.
- Examples, templates, and structure tests.

## Compatibility

- Compatible with ZIP01 through ZIP13.
- Does not replace ZIP08 scheduler, ZIP11 dashboard, ZIP12 rendering, or ZIP13 AI runtime.
- Adds a routing layer for devices and workers.

## Non-Goals

- No real mobile control implementation.
- No platform bypass.
- No spam automation.
- No SaaS conversion.
- No mandatory cloud or database.
