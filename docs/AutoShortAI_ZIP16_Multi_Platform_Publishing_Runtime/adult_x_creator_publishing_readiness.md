# Adult / X Creator Publishing Readiness

AutoShortAI must support all platform categories over time, including creators who operate 18+ accounts.

This does not make the product adult-only. It defines a dedicated restricted module path:

```text
General Publishing Runtime
    └── Restricted Adult / X Creator Publishing Adapter Layer
```

Rules:

- opt-in only
- disabled by default
- isolated accounts
- isolated credentials
- restricted assets
- sanitized logs
- maturity rating required
- consent metadata required
- all participants 18+ required
- age-gate required
- manual review required

Future adapters may target adult creator platforms such as OnlyFans-style or Fansly-style platforms only through these restricted contracts.
