# Restricted / Adult Platform Readiness

AutoShortAI must be able to support users who create for adult / 18+ platforms later, without making the core adult-only.

ZIP13 introduces restricted platform readiness through:

- maturity ratings
- restricted platform category markers
- consent requirements
- age gate requirements
- manual review gates
- platform policy hooks
- output validation before rendering/publishing

Adult / 18+ platform publishing is not implemented in ZIP13. It belongs in future platform publishing runtime and security vault ZIPs.
