# Learning Core

The Learning Core converts normalized performance evidence into `LearningInsight` objects.

Inputs may include:

- ZIP09 metrics snapshots,
- ZIP09 feedback results,
- ZIP07 creative profiles,
- ZIP07 content variants,
- ZIP08 job outcomes,
- ZIP06 cost metadata.

Outputs must be safe and reviewable:

- insight summary,
- affected platforms,
- affected strategy/profile IDs,
- confidence level,
- suggested next action.

The core must remain deterministic by default. AI-assisted reasoning may be added later as an optional provider.
