# ZIP10 Changelog

## Added

- Auto-learning adaptation architecture.
- Learning core contracts.
- Adaptation suggestion models.
- Confidence and safety layer models.
- Learning memory contracts.
- Experiment learning models.
- Adaptation policy enums and evaluators.
- Feedback-to-strategy bridge interfaces.
- Platform-agnostic learning profile contracts.
- ZIP10 hooks.
- Templates, examples and structure tests.

## Preserved

- ZIP01 to ZIP09 compatibility.
- Plugin-first architecture.
- Lightweight local-first design.
- Platform-agnostic core rule.
- No SaaS assumptions.
- No mandatory database.

## Not included

- Guardian Engine.
- Heavy dashboard.
- Complete video rendering.
- Real AI worker runtime.
- Uncontrolled automatic learning.
- Single-platform coupling.
