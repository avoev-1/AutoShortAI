# Cadence Model

Cadence defines production rhythm.

## Supported cadence concepts

- daily
- weekly
- custom interval
- campaign window
- platform-specific schedule
- blackout dates
- timezone
- max jobs per period

## Examples

```text
YouTube Shorts: 2 per day
TikTok: 3 variants per day
Instagram Reels: 1 clean export per day
```

ZIP08 defines cadence contracts only. Actual platform intelligence belongs to future releases.
