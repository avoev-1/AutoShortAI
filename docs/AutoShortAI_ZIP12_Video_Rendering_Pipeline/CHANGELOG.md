# CHANGELOG — ZIP12 Video Rendering Pipeline

## Added

- Rendering core architecture.
- Timeline engine contracts.
- Video project, scene, track, clip, overlay, subtitle, audio, and export models.
- Multi-platform render profiles.
- Template rendering contracts.
- Subtitle and caption contracts.
- Audio layer contracts.
- Worker interfaces.
- Draft/final render modes.
- Rendering hooks.
- Structure tests and examples.

## Changed

- No previous ZIP contract is modified.
- No previous module namespace is renamed.

## Removed

- Nothing.

## Compatibility

ZIP12 is additive and compatible with ZIP01 through ZIP11.
