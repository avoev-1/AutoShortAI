# Multi-Platform Render Profiles

ZIP12 render profiles must be platform-agnostic and capability-driven.

Initial profiles:

- youtube_shorts_9x16
- tiktok_9x16
- instagram_reels_9x16
- facebook_reels_9x16
- snapchat_spotlight_9x16
- x_twitter_video
- generic_vertical_video
- generic_square_video
- generic_landscape_video

Profiles define ratio, resolution, FPS, codec preference, bitrate, safe zones, duration targets, and export containers.

The core must never assume YouTube is the only target.
