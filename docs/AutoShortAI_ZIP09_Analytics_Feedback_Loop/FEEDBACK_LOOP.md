# Feedback Loop Engine

The Feedback Loop Engine transforms performance data into human-readable and machine-readable observations.

## Allowed output

- feedback summaries
- performance notes
- warnings
- opportunities
- experiment observations
- recommendations for future manual review

## Forbidden in ZIP09

- automatic strategy mutation
- automatic creative profile edits
- automatic platform prioritization changes
- automatic job scheduling changes

Those actions belong to ZIP10 or later releases.

## Example observations

- The mysterious hook variant outperformed the direct hook variant on completion rate.
- The finance explainer profile had high retention but low engagement.
- TikTok performance improved on short time windows while YouTube performed better after 24h.
