# Performance Scoring

ZIP09 defines contracts for scoring content performance without hardcoding one platform's definition of success.

## Scores

- visibility_score
- retention_score
- engagement_score
- growth_score
- platform_fit_score
- cost_efficiency_score
- overall_performance_score

## Scoring principles

- Scores must accept missing metrics.
- Scores must expose confidence.
- Scores must preserve platform context.
- Scores must be comparable across platforms only after normalization.
- Scores must not mutate production or strategy state.
