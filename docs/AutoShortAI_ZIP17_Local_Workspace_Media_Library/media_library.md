# Media Library

The Media Library gives AutoShortAI a stable way to organize media files across projects.

## Media types

- script
- image
- audio
- video
- subtitle
- thumbnail
- metadata
- template
- export

## Index goals

The index should support:

- tags
- collections
- creative profiles
- platform targets
- language
- maturity rating
- review status
- storage references
- asset fingerprints from ZIP06
- performance scores from ZIP09 later

## Non-goals

- no mandatory SQL database
- no cloud sync requirement
- no platform-specific lock-in
- no secrets storage
