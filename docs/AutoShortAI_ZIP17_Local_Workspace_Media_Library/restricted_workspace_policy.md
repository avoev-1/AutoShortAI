# Restricted Workspace Policy

Restricted workspaces support future Adult / X Creator workflows as a dedicated opt-in category.

## Required safeguards

- Disabled by default.
- Isolated from general workspace.
- Separate media indexes.
- Separate export folders.
- Maturity rating required.
- Consent metadata required.
- All participants must be 18+.
- Manual review required by default.
- Restricted logs must be separated.
- No unsafe automatic publishing.

## Forbidden content

- illegal content
- non-consensual content
- underage content
- content without required consent metadata
- restricted assets copied into general workspaces
- automatic publishing without review in restricted mode
