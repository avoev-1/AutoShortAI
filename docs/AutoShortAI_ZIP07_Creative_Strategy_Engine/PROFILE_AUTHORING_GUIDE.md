# Profile Authoring Guide

Profiles should be small, readable, and versioned.

A profile should include:

- stable id;
- platform target;
- content format;
- duration bounds;
- narrative blocks;
- style tags;
- visual tags;
- audio tags;
- risk level;
- estimated cost ceiling;
- required asset kinds.

Profiles should avoid embedding provider-specific prompts directly. Provider prompt templates should remain external and replaceable.
