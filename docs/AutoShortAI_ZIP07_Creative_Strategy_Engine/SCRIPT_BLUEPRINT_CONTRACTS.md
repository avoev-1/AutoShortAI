# Script Blueprint Contracts

Script blueprints define structure, not final copy.

Required block types:

- hook;
- context;
- value;
- twist;
- call-to-action.

A typical short-form structure:

```text
0-3s: hook
3-10s: context
10-25s: value
25-32s: twist or payoff
32-38s: light CTA
```

Implementations may adapt timing per profile and platform.
