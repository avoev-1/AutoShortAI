# Creation Profiles

Creation profiles are reusable presets that describe how content should be shaped.

A profile may define:

- target platform;
- format;
- duration range;
- pacing;
- energy level;
- narrative structure;
- visual direction;
- audio direction;
- CTA style;
- risk tolerance;
- cost ceiling;
- asset requirements.

Profiles must be data-first. They should be editable without rewriting core code.
