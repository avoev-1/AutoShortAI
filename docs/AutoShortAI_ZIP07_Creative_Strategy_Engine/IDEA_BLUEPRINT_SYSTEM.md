# Idea Blueprint System

The Idea Blueprint System turns an initial creative intent into structured strategy objects.

Main concepts:

- `ContentIdea`: the base idea.
- `ContentAngle`: the framing used to make the idea interesting.
- `ContentHook`: the opening attention mechanism.
- `ContentPromise`: what the viewer receives by watching.
- `TargetAudience`: who the content is designed for.

This layer must not generate a full final script. It only prepares structured creative intent.
