# ZIP06 Changelog

- Smart Asset Pipeline architecture documentation.
- Python contracts for asset registry, fingerprinting, dependency graph, incremental build, cache, resume, checkpoint, integrity, storage, provider abstraction, API cost optimization, performance profiling, and hooks.
- Shared models for asset identity, fingerprints, cache policy, checkpoints, storage locations, cost estimates, and performance samples.

- Templates for asset manifests, cache policy, providers, checkpoints, and cost profiles.
- Structure tests and fixtures.
- INSTALL and VERIFY scripts designed to run from `~/Projects/AutoShortAI`.

## Changed

- No previous ZIP files are modified by design.

## Removed

- Nothing.
